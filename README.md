# 单词故事生成器（儿童英语四件套）

输入一个英文单词，一键生成：**儿童英语小故事 + 配音朗读 MP3 + 逐词字幕视频（含 3 秒 "What's this?" 片头）+ 引流封面**。

纯前端网页应用，免费部署到 GitHub Pages，长期使用；配音与豆包故事走**一次配置、永久免费**的自托管中继。

---

## 一、文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 应用本体（单文件，含全部逻辑） |
| `bg.PNG` | 视频/封面统一背景图（可随时替换） |
| `tts-relay/worker.js` | 免费中继 · Cloudflare Workers 版（**推荐部署**，粘贴即用） |
| `tts-relay/index.js` | 免费中继 · Node 版（自建服务器 / 本地用） |
| `README.md` | 本文档 |

部署后浏览器会自动按 `bg.png → bg.PNG → bg.jpg` 顺序寻找背景图；换成你自己的图，**命名为 `bg.png` 放同目录即可**（任意竖版图片均可，建议接近 9:16，如 1080×1920）。

## 二、本地运行

双击 `index.html` 即可使用（推荐），或用任意静态服务器：

```bash
python -m http.server 8080
# 打开 http://localhost:8080
```

## 三、配置免费中继（一次约 3 分钟，永久免费）

**为什么需要它**：GitHub Pages 是纯静态托管；浏览器直接连接微软 Edge 语音服务会被拒绝（403，浏览器无法发送微软要求的握手头），豆包接口同样拦截浏览器跨域。因此需要一个极小的"中继"：把文字转发给语音/模型服务，拿回**音频 + 逐词时间戳**。它部署在免费平台上，只服务你自己的网页，**无任何使用费**。

### 方式 A：Cloudflare Workers（推荐，粘贴代码即用，无需 Git）
1. 打开 https://workers.cloudflare.com → 登录/注册 → 点 **Create Worker**（或进入 Workers & Pages → Create → Worker）；
2. 把 `tts-relay/worker.js` 的**全部代码**粘贴进编辑器，覆盖默认代码；
3. 点 **Deploy**（部署）→ 得到网址 `https://xxxx.你的子域.workers.dev`；
4. 打开应用 → **设置** → 在"配音 TTS 中继地址"填入 `https://xxxx.你的子域.workers.dev`（不带路径）→ 保存。

免费计划每天 10 万次请求，个人使用绰绰有余；该中继同时提供 `/tts`（配音）与 `/llm`（豆包故事转发）。

### 方式 B：自己服务器 / 本地（Node）
```bash
cd tts-relay
npm install ws
node index.js          # 监听 8899，可用 PORT 环境变量改端口
```
中继接口：`GET /tts?text=Hello&voice=en-US-JennyNeural&rate=-8%`，返回 `{"audio":"<mp3 base64>","words":[{word,start,dur}],"duration":秒}`；`POST /llm` 转发豆包等模型请求。

> 未配置中继时：故事、封面仍可生成，并提供系统语音试听；视频配音与豆包故事需要中继。

## 四、部署到 GitHub Pages（免费、长期）

1. 在 GitHub 新建一个仓库（Public 或 Private 均可）；
2. 把 `index.html`、`bg.PNG`（以及 `README.md`、`tts-relay/`）上传到仓库根目录；
3. 仓库 → **Settings → Pages** → Source 选 `Deploy from a branch` → 分支选 `main`、目录选 `/ (root)` → Save；
4. 等 1–2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。
5. 以后想更新背景图或页面，直接推送新文件，GitHub Pages 会自动更新。

> 提示：也可用 GitHub Desktop 或网页端拖拽上传，不需要命令行。

## 五、使用方法

1. 输入一个单词（如 `ball`、`cat`、`sun`）；
2. 点 **一键生成四件套**；
3. 依次得到：故事文本（可编辑）→ 配音 MP3 → 逐词字幕视频 → 封面 PNG；
4. 下载或预览，把视频/封面发到抖音、小红书等平台引流。

## 六、设置项说明

| 设置 | 说明 |
| --- | --- |
| 故事模型 | 内置模板（免配置，始终可用）/ 豆包（免费额度，经中继）/ 智谱 GLM Flash（免费，直连）/ Gemini（可选）。切换后按提示填对应 Key |
| 配音 TTS 中继地址 | 见第三节，配置后自动启用高品质配音 + 精确逐词字幕；豆包故事也走该中继 |
| 豆包 / 智谱 / Gemini API Key | 只保存在你自己的浏览器 localStorage，不上传任何服务器。免费申请：豆包 https://console.volcengine.com/ark（新用户每模型送 50 万 tokens，另有"安心体验模式"）；智谱 https://open.bigmodel.cn（GLM Flash 系列永久免费）；Gemini https://aistudio.google.com/apikey |
| 模型（按所选故事模型） | 豆包默认 `doubao-seed-1.6-flash`；智谱默认 `glm-4-flash`（可换 `glm-4.5-flash` 等免费模型）；Gemini 默认 `gemini-2.5-flash` |
| 朗读音色 | 默认 **Ana 美音童声**（适合儿童），可换 Jenny 美音女声等 |
| 朗读语速 | 默认 -8%（较慢，适合 4-6 岁）；故事长短不合适可调 |
| 视频比例 | 默认**竖屏 9:16**（抖音/小红书主流）。若需横屏选 16:9 |
| 背景 | 默认自动读取 `bg.png`；可选内置背景 |
| 视频输出 | 默认自动（电脑最快路径）；勾选"始终输出 MP4"用 ffmpeg 合成，兼容性最好但较慢 |

## 七、技术原理（免费如何成立）

- **故事**：**默认由模型按单词实时生成**（不再套固定模板），可写贴合词性的情节——物件就介绍它是什么/在哪/谁用它，不会拟人成"朋友/跳舞"。也可在首页文本框**粘贴自己的英文文案**（一行一句，句后用 `|` 带中文翻译），贴了就直接用。未配 Key 或模型失败时降级内置模板，并在故事区给出醒目提示；
- **配音**：应用按优先级自动选择 —— ① 自托管中继（推荐，Edge 高品质语音 + 精确逐词时间戳）→ ② 浏览器直连 Edge（部分环境可能放开）→ ③ 系统语音试听（无视频配音）。中继代码见 `tts-relay/`，可自行审计；
- **视频**：Canvas 逐词高亮 + WebAudio 同步 + MediaRecorder 原生录制（电脑/安卓最快）；不支持的环境（如 iPhone/iPad Safari）自动切换 **ffmpeg.wasm** 在浏览器内合成 MP4（首次需下载约 30MB 引擎，之后有缓存）；
- **封面**：Canvas 本地绘制，零依赖。

## 八、注意事项

- **配音接口是非官方免费接口**：微软未承诺长期开放，若某天不可用，页面会自动降级，不影响其他功能；
- **免费额度政策会变**：豆包/智谱/Gemini 的免费额度可能调整，遇到报错换模型或模型名即可；本应用核心链路不依赖任何付费 API；
- **iOS 视频生成较慢**：iPhone/iPad 首次用 ffmpeg 合成需下载引擎并逐帧编码，请耐心等待进度条；
- **视频默认 9:16 竖屏**：需求中"16:9 竖屏"按竖屏 9:16 实现（短视频平台惯例），横屏可在设置里一键切换。
